# Portal do convidado

Rota pública: `/portal/:token` (sem login da equipe).

## Para a equipe
Gere o link no detalhe da visita → Portal do visitante. Envie o link/QR. Use “Gerar mensagem” para um texto de convite.

## Para o convidado
Com o link, o visitante confirma presença, revisa dados e vê a programação. Avaliações aparecem no detalhe da visita para a equipe.
