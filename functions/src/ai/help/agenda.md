# Programação (Agenda)

Rota: `/agenda`

## O que é
A Programação mostra a agenda detalhada de **uma visita** (lista ou semana). Selecione a visita no filtro no topo.

## Como criar um compromisso / atividade
1. Abra **Programação** no menu lateral.
2. Escolha a visita no seletor.
3. Clique em **Nova atividade** (ou equivalente com ícone +).
4. Preencha título, data, horário de início e fim.
5. Opcional: local, descrição, responsáveis e visitantes.
6. Salve. Se o Google Calendar estiver conectado, a atividade pode ser sincronizada.

## Como importar programação de arquivo
1. Com uma visita selecionada, use **Importar arquivo** (Excel/planilha).
2. Confira o preview das atividades extraídas.
3. Se o parser local falhar ou o layout for incomum, use **Interpretar com IA**.
4. Revise avisos (conflitos, linhas ignoradas) e clique em **Salvar programação**.
O arquivo não fica armazenado no sistema.

## Google Calendar
Em **Configurações**, conecte a conta Google. Depois sincronize atividades individuais ou a visita inteira na Programação.
