Objetivo do dia:
1. Infra Firebase Functions (1ª vez neste repo):
   - Pasta functions/ (Node + TypeScript) com scripts de build/deploy.
   - Atualizar firebase.json com "functions".
   - NÃO commitar client secret. Usar functions config / .env da pasta functions
     (functions/.env no .gitignore) / Secret Manager.
   - Documentar no próprio dia (comentário no README da functions ou no 00 não precisa
     ser editado): GOOGLE_CLIENT_ID, GOOGLE_CLIENT_SECRET, redirect URI
     `https://<region>-<project>.cloudfunctions.net/googleCalendarOAuthCallback`
     e também localhost para emulador se der tempo.
2. Coleção `calendarConnections`:
   - ownerId (uid)
   - provider: 'google' | 'outlook'
   - google: refreshToken (NUNCA enviar ao cliente), email da conta, connectedAt
   - outlook: não preencher hoje
   Rules: somente o dono lê um documento "público" SEM o refreshToken.
     Melhor: a Function grava o refreshToken em campo que o cliente não precisa ler.
     Exponha ao cliente só { provider, email, connected: true } via get mascarado
     OU coleção calendarConnectionPublic + secrets só no Admin SDK.
     Padrão recomendado: Functions usam Admin SDK; rules do cliente:
     allow read: resource.data.ownerId == uid e NÃO incluir refreshToken no doc que o
     cliente lê. Se for um único doc, as rules Firestore não mascaram campos —
     então use dois docs OU só acesse o status via HTTPS callable `getCalendarStatus`.
     Prefira callable getCalendarStatus + connect/disconnect para não vazar token.
3. Fluxo OAuth Google:
   - Callable ou HTTPS `googleCalendarOAuthStart` devolve a URL de consentimento
     (scope calendar.events).
   - Callback troca code por tokens, salva refreshToken (Admin SDK), redireciona
     o usuário de volta ao app `/configuracoes?calendar=connected`.
   - `googleCalendarDisconnect` revoga token se possível e apaga a conexão.
4. UI em Configurações:
   - Card "Calendários externos"
   - Google: botão Conectar / Desconectar + e-mail conectado.
   - Outlook: botão desabilitado "Em breve".
5. Types CalendarProvider, CalendarConnectionStatus em src/types/index.ts.
6. Se o ambiente não tiver credenciais Google, a UI mostra:
   "Defina GOOGLE_CLIENT_ID e GOOGLE_CLIENT_SECRET nas Functions" — app não quebra.
